# Tawleh Manager

Restaurant table-service operating system prototype.

## Structure

- app/page.tsx
- app/globals.css
- app/layout.tsx
- package.json

## Run

```powershell
cd C:\Users\HP\Desktop\tawleh-manager
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Workflow

Edit:

```text
app/page.tsx
app/globals.css
```

Save, then refresh/browser updates.

## Current prototype includes

- Restaurant signup
- Restaurant logo upload
- Brand color
- Customer "Have a Seat" flow
- Multiple names on the same table
- Kitchen orders by table and customer name
- Waiter call requests
- Table bill grouped by guest
- Menu availability manager
- Table QR creator
- Printable QR card
